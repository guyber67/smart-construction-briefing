# Smart Construction Briefing

스마트건설·건설 AI·AX·DX 데일리 브리핑을 같은 URL에서 제공하는 정적 웹앱입니다.

## 구조

- `index.html`: 브리핑 화면과 키워드·날짜·지역·분야 검색 필터
- `data/briefings.json`: 날짜별 브리핑 누적 데이터
- `scripts/validate-briefings.mjs`: 필수 필드, 동일 URL, 유사 제목, 원문 링크 검사

## 매일 업데이트

매일 오전 6시 브리핑 생성 후 `data/briefings.json` 배열 맨 앞에 새 날짜 객체를 추가하고 `main` 브랜치에 반영합니다. GitHub Pages가 같은 주소에 최신 내용을 자동 배포합니다.

기존 날짜 데이터는 삭제하지 않고 계속 보관합니다.

새 브리핑에는 경영진 핵심 결론 2~3개와 기사별 출처 유형, 발행일, 브리핑 등록일, 원문 확인일, `왜 중요한가`, `우리에게 필요한 대응`을 포함합니다. 동일 URL이나 제목 유사도 88% 이상인 기사는 후속 보도로 연결되지 않은 경우 게시하지 않습니다.

GitHub Actions가 매일 오전 6시 5분(KST)에 누적 데이터와 원문 링크 상태를 자동 점검합니다.
